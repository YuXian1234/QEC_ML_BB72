Tensor-Network Decoder for BB72

From the BB72 code layout to syndrome processing, logical cosets, tensor-network contraction, logical posteriors, and correction.
Scope. We begin with the setting: the BB72 code under code-capacity noise, with independent \(X\) errors and perfect syndrome measurements. This is the simplest setting in which the logical-coset tensor-network decoder can be understood and implemented correctly. Extensions to full Pauli noise, depolarizing noise, correlated noise, and circuit-level noise can be added later.

1. What is the decoding problem?

Suppose an unknown physical \(X\)-error pattern \(e\in\mathbb F_2^{72}\) occurs on the BB72 data qubits. The measured \(Z\)-syndrome is

\[ s = H_Z e^T. \]

The decoder receives \(s\), not the true error \(e\). Its task is not necessarily to reconstruct the exact physical error pattern. Instead, it must determine which logical equivalence class contains the true error.

Why do we sum the probability of an entire logical coset?

Choose any one error \(e_0\) that produces the measured syndrome,

\[ H_Ze_0^T=s. \]

Errors with the same syndrome can differ in two qualitatively different ways. First, they may differ by a logical operator \(\lambda L_X\). This changes their logical action. Second, they may differ by an \(X\)-stabilizer \(g\in\mathcal S_X\). Multiplying by a stabilizer does not change the encoded logical state, because every stabilizer acts as the identity on the code space:

\[ g|\psi_L\rangle=|\psi_L\rangle. \]

Therefore, for a fixed logical label \(\lambda\), the physical errors

\[ e_0+\lambda L_X, \qquad e_0+\lambda L_X+g_1, \qquad e_0+\lambda L_X+g_2, \qquad \ldots \]

all have the same logical effect. A decoder that applies a correction from this same equivalence class succeeds for all of them. Hence the decoder should not compare only one representative error; it should compare the total probability mass of all physically different errors that are logically equivalent.

Important precision. \(e_0+\lambda L_X+g\) has the same logical effect as \(e_0+\lambda L_X\), not necessarily as \(e_0\). It has the same effect as \(e_0\) only when \(\lambda=0\). The stabilizer \(g\) is logically invisible; the logical operator \(\lambda L_X\) is not.

Because the physical error patterns in one logical coset are mutually exclusive noise events, their probabilities add. This gives the central quantity

\[ \boxed{ Z_{\lambda}(s) = \sum_{g\in\mathcal S_X} P\!\left(e_0+\lambda L_X+g\right). } \]

Thus \(Z_\lambda(s)\) is the probability mass of the entire logical sector \(\lambda\), restricted to the measured syndrome \(s\). The maximum-likelihood logical decoder chooses

\[ \lambda^\star = \arg\max_{\lambda} Z_{\lambda}(s). \]

2. The BB72 code

The standard BB72 bivariate bicycle code has parameters

\[ [[72,12,6]], \]

with

\[ \ell=m=6. \]

Define the two \(36\times36\) binary matrices

\[ A=x^3+y+y^2, \qquad B=y^3+x+x^2, \]

where \(x\) and \(y\) are cyclic shift operators on the two periodic directions. The CSS parity-check matrices are

\[ H_X=[A\mid B], \qquad H_Z=[B^T\mid A^T]. \]

Both have shape

\[ 36\times72. \]

The 72 physical qubits are naturally divided into two sets of 36:

\[ L_{a,b}, \qquad R_{a,b}, \qquad a,b\in\mathbb Z_6. \]

A convenient indexing convention is

\[ i_L(a,b)=6a+b, \] \[ i_R(a,b)=36+6a+b. \]

Every \(X\)-check and every \(Z\)-check has weight 6. Every physical qubit participates in three \(X\)-checks and three \(Z\)-checks. The two \(6\times6\) qubit arrays are periodic: the coordinate arithmetic below is always modulo 6.

3. From a physical error to a syndrome

3.1 Which qubits are connected to each stabilizer check?

With the indexing convention used in this document, the 36 \(X\)-checks are generated by translating

\[ \boxed{ S^X_{a,b} = X_{L_{a+3,b}} X_{L_{a,b+1}} X_{L_{a,b+2}} X_{R_{a,b+3}} X_{R_{a+1,b}} X_{R_{a+2,b}}, } \]

and the 36 \(Z\)-checks are generated by

\[ \boxed{ S^Z_{a,b} = Z_{L_{a,b+3}} Z_{L_{a-2,b}} Z_{L_{a-1,b}} Z_{R_{a+3,b}} Z_{R_{a,b-2}} Z_{R_{a,b-1}}. } \]

All indices are understood modulo 6. Therefore these two formulas explicitly specify every stabilizer-to-qubit connection in BB72.

For example,

\[ S^X_{0,0} = X_{L_{3,0}} X_{L_{0,1}} X_{L_{0,2}} X_{R_{0,3}} X_{R_{1,0}} X_{R_{2,0}}, \]

whereas

\[ S^Z_{0,0} = Z_{L_{0,3}} Z_{L_{4,0}} Z_{L_{5,0}} Z_{R_{3,0}} Z_{R_{0,4}} Z_{R_{0,5}}. \]

3.2 Example: one physical \(X\) error

Assume, for testing purposes, that the true physical error is an \(X\) error on a single qubit, for example \(L_{0,0}\). In binary form, \(e_{\rm true}\) is a 72-bit vector with a single 1.

The measured syndrome is

\[ s=H_Z e_{\rm true}^T. \]

Because only one entry of \(e_{\rm true}\) is nonzero, \(s\) is simply the \(L_{0,0}\) column of \(H_Z\).

From the general \(Z\)-check formula above, \(L_{0,0}\) belongs to exactly three \(Z\)-checks:

\[ S^Z_{0,3}, \qquad S^Z_{1,0}, \qquad S^Z_{2,0}. \]

Therefore an \(X\) error on \(L_{0,0}\) anticommutes with exactly those three \(Z\)-stabilizers and flips exactly those three syndrome bits. In the row ordering \(6a+b\), the nonzero syndrome positions are

\[ 3,\qquad 6,\qquad 12. \]
The decoder does not know that the true error was \(X_{L_{0,0}}\). It receives only the syndrome \(s\). The example is used only to verify that the algebra and the check connectivity are consistent.

4. Find one representative error \(e_0\)

Given \(s\), the first algebraic step is to find any binary vector \(e_0\) satisfying

\[ H_Z e_0^T=s. \]

This can be obtained by Gaussian elimination over \(\mathbb F_2\).

The representative \(e_0\) does not need to be the true error and does not need to be the most likely error. It is simply one point in the affine space of all error patterns consistent with the measured syndrome.

Every error with the same syndrome can be written relative to this starting point.

5. Why logical \(X\) operators live in \(\ker H_Z\)

An \(X\)-type binary vector \(v\) produces the \(Z\)-syndrome

\[ H_Zv^T. \]

Why must a logical \(X\) produce zero syndrome? The reason is that a logical operator must map the code space back into the code space.

5.1 Code-space argument

Let \(S_a^Z\) be one \(Z\)-stabilizer. Every encoded state \(|\psi_L\rangle\) satisfies

\[ S_a^Z|\psi_L\rangle=|\psi_L\rangle. \]

If \(\overline X\) is a genuine logical \(X\) operator, then the state

\[ \overline X|\psi_L\rangle \]

must still lie in the code space. It must therefore also satisfy

\[ S_a^Z\overline X|\psi_L\rangle = \overline X|\psi_L\rangle. \]

This is guaranteed when

\[ S_a^Z\overline X = \overline X S_a^Z. \]

Indeed,

\[ S_a^Z\overline X|\psi_L\rangle = \overline X S_a^Z|\psi_L\rangle = \overline X|\psi_L\rangle. \]

If \(S_a^Z\) and \(\overline X\) anticommute instead, then

\[ S_a^Z\overline X|\psi_L\rangle = -\overline X|\psi_L\rangle, \]

so the stabilizer eigenvalue changes from \(+1\) to \(-1\). That is precisely a nonzero syndrome, and the state has left the code space.

5.2 Binary commutation condition

Write the support of \(S_a^Z\) as a binary row vector \(h_a\), and the support of the \(X\)-type operator as \(L\). Every position on which both vectors contain a 1 contributes one \(ZX=-XZ\) anticommutation sign. Hence

\[ S_a^Z\overline X = (-1)^{h_aL^T} \overline X S_a^Z, \]

where \(h_aL^T\) is evaluated modulo 2. Therefore

\[ S_a^Z\overline X = \overline X S_a^Z \quad\Longleftrightarrow\quad h_aL^T=0\pmod2. \]

Demanding this for every row \(h_a\) of \(H_Z\) gives

\[ \boxed{ H_ZL^T=0. } \]

Thus every logical \(X\) representative lies in

\[ \boxed{ \ker H_Z = \{v\in\mathbb F_2^{72}:H_Zv^T=0\}. } \]

5.3 Why \(\ker H_Z\) is larger than the logical-\(X\) space

The kernel also contains all \(X\)-stabilizers. The CSS commutation condition

\[ H_ZH_X^T=0 \]

means that every row of \(H_X\) belongs to \(\ker H_Z\). These rows act trivially on the code space and therefore do not represent nontrivial logical operations.

Consequently the true logical-\(X\) space is the quotient

\[ \boxed{ \ker H_Z/\operatorname{row}(H_X). } \]

For BB72,

\[ \operatorname{rank}(H_Z)=30, \qquad \dim\ker H_Z=72-30=42, \]

and

\[ \operatorname{rank}(H_X)=30. \]

Therefore

\[ \dim\!\left( \ker H_Z/\operatorname{row}(H_X) \right) = 42-30 = 12, \]

which is exactly the number \(k=12\) of encoded logical qubits.

6. Construct a logical-\(X\) basis

Choose 12 independent representatives of

\[ \ker H_Z/\operatorname{row}(H_X), \]

and arrange them as the rows of

\[ L_X\in\mathbb F_2^{12\times72}. \]

A useful feature of BB72 is that, with the cyclic-shift and qubit-index convention used in this document, one can choose a complete logical-\(X\) basis in which all 12 representatives have weight 6. \[ H_Z\overline X_j^T=0, \]

\[ \operatorname{rank} \begin{pmatrix} H_X\\ L_X \end{pmatrix} = 30+12 = 42 = \dim\ker H_Z. \]

If one later needs canonical pairs \((\overline X_j,\overline Z_j)\) for individually named logical qubits, the \(X\)- and \(Z\)-logical bases can be symplectically paired. For computing the \(2^{12}\) logical-coset probabilities, however, any valid independent quotient basis is sufficient.

7. Label the logical sectors by \(\lambda\)

Introduce a 12-bit logical label

\[ \lambda=(\lambda_1,\ldots,\lambda_{12}) \in\mathbb F_2^{12}. \]

The binary vector

\[ \lambda L_X = \lambda_1\overline X_1 +\cdots+ \lambda_{12}\overline X_{12} \]

specifies which logical \(X\) operators are included.

Since there are 12 independent logical bits, there are

\[ 2^{12}=4096 \]

logical \(X\) sectors.

For a chosen \(\lambda\), define the sector representative

\[ b^{(\lambda)} = e_0+\lambda L_X. \]

Because every row of \(L_X\) lies in \(\ker H_Z\),

\[ H_Z b^{(\lambda)T} = H_Ze_0^T + H_Z(\lambda L_X)^T = s. \]

Thus every \(b^{(\lambda)}\) has exactly the measured syndrome \(s\).

8. Generate all stabilizer-equivalent errors in one logical sector

The \(X\)-stabilizer group is generated by the rows of \(H_X\).

Introduce 36 binary generator variables

\[ u=(u_1,\ldots,u_{36}) \in\mathbb F_2^{36}. \]

The vector

\[ uH_X \]

represents the product of the selected \(X\)-stabilizer generators.

Therefore every physical error in logical sector \(\lambda\) can be written as

\[ \boxed{ e(u,\lambda) = e_0+\lambda L_X+uH_X. } \]

Equivalently,

\[ e(u,\lambda) = b^{(\lambda)}+uH_X. \]

For fixed \(\lambda\), varying \(u\) moves around inside the same logical coset. Varying \(\lambda\) moves between different logical cosets.

9. Why the 36 stabilizer variables overcount by a factor of 64

Although \(H_X\) has 36 rows, only 30 are independent:

\[ \operatorname{rank}(H_X)=30. \]

Therefore the linear map

\[ u\mapsto uH_X \]

has a 6-dimensional kernel:

\[ \dim\ker(u\mapsto uH_X) = 36-30=6. \]

Hence every actual stabilizer is represented by

\[ 2^6=64 \]

different choices of \(u\).

If we keep all 36 generator variables in the tensor network, the exact coset probability is therefore

\[ \boxed{ Z_{\lambda}(s) = \frac{1}{2^6} \sum_{u\in\mathbb F_2^{36}} P\!\left(b^{(\lambda)}+uH_X\right). } \]

The factor \(2^{-6}\) is unnecessary if one only compares different logical sectors, because it is common to all \(\lambda\). It is needed only when one wants the absolute coset probability itself.

10. Independent \(X\)-noise factorizes over qubits

Assume independent \(X\)-noise with physical error probability \(p_i\) on qubit \(i\). Then

\[ P(e) = \prod_{i=1}^{72}P_i(e_i), \]

where

\[ P_i(0)=1-p_i, \qquad P_i(1)=p_i. \]

For uniform noise, \(p_i=p\) for all qubits.

The key observation is that each physical qubit participates in exactly three \(X\)-checks. If the three neighboring stabilizer variables are \(u,v,w\), then the final error bit on that qubit is

\[ \epsilon_i = b_i^{(\lambda)} \oplus u\oplus v\oplus w. \]

The XOR appears because multiplying an \(X\) operator twice on the same qubit gives identity:

\[ X_i^2=I. \]

Only the parity of the number of \(X\) factors matters.

11. The qubit probability tensor

For each physical qubit \(i\), define a rank-3 tensor

\[ W_i^{(b_i)}(u,v,w) = P_i\!\left( b_i^{(\lambda)} \oplus u\oplus v\oplus w \right). \]

Explicitly,

\[ W_i^{(b_i)}(u,v,w) = \begin{cases} 1-p_i, & b_i^{(\lambda)} \oplus u\oplus v\oplus w=0, \\[1mm] p_i, & b_i^{(\lambda)} \oplus u\oplus v\oplus w=1. \end{cases} \]

Thus every qubit tensor has shape

\[ 2\times2\times2. \]

Its three indices correspond to the three \(X\)-stabilizer variables touching that physical qubit.

12. The stabilizer COPY tensor

Each \(X\)-stabilizer acts on six physical qubits. Its binary selection variable must therefore be passed consistently to six different qubit tensors.

Introduce a rank-6 COPY tensor

\[ C(\alpha_1,\ldots,\alpha_6) = \begin{cases} 1, & \alpha_1=\alpha_2=\cdots=\alpha_6, \\ 0, & \text{otherwise}. \end{cases} \]

Each index is binary, so the tensor has

\[ 2^6=64 \]

entries. Only two are nonzero:

\[ C_{000000}=1, \qquad C_{111111}=1. \]

This enforces the statement that a stabilizer generator is either not selected at all, or selected as a whole. It cannot be “selected” on only some of the six qubits in its support.

Equivalently,

\[ C(\alpha_1,\ldots,\alpha_6) = \sum_{u=0}^{1} \delta_{\alpha_1,u} \cdots \delta_{\alpha_6,u}. \]

13. The complete BB72 tensor network

For one fixed syndrome \(s\) and one fixed logical label \(\lambda\), the tensor network contains:

Tensor type Number Rank Role
Stabilizer COPY tensor 36 6 Replicates one stabilizer variable to its six neighboring qubits
Qubit probability tensor 72 3 Assigns the local physical-error probability

The total number of incidence bonds is

\[ 36\times6 = 72\times3 = 216. \]

The network connectivity is determined directly by the nonzero pattern of \(H_X\):

  • each row of \(H_X\) specifies the six qubit tensors connected to one COPY tensor;
  • each column of \(H_X\) specifies the three COPY tensors connected to one qubit tensor.

The contraction of this network performs the sum over all stabilizer configurations simultaneously.

14. What does the contraction compute?

The partition function can be written directly as the contraction of the tensors introduced in Section 13. Let \(C_c\) denote the rank-6 COPY tensor for \(X\)-check \(c\), and let \(W_i^{(b_i^{(\lambda)})}\) denote the rank-3 probability tensor for physical qubit \(i\). Then

\[ \boxed{ \widetilde Z_\lambda(s) = \operatorname{tTr} \left[ \prod_{c=1}^{36} C_c \prod_{i=1}^{72} W_i^{(b_i^{(\lambda)})} \right]. } \]

Here \(\operatorname{tTr}\) means that every incidence index connecting a stabilizer COPY tensor to a qubit tensor is contracted. Writing the same contraction with all indices exposed gives

\[ \widetilde Z_\lambda(s) = \sum_{\{\alpha_{ci}\}} \left[ \prod_{c=1}^{36} C_c\!\left( \{\alpha_{ci}\}_{i\in N(c)} \right) \right] \left[ \prod_{i=1}^{72} W_i^{(b_i^{(\lambda)})} \!\left( \{\alpha_{ci}\}_{c\in N_X(i)} \right) \right]. \]

The COPY tensor forces all six indices adjacent to check \(c\) to take one common binary value \(u_c\). Once this constraint is imposed, the general tensor-contraction expression reduces exactly to

\[ \widetilde Z_\lambda(s) = \sum_{u\in\mathbb F_2^{36}} \prod_{i=1}^{72} P_i\!\left( b_i^{(\lambda)} \oplus \bigoplus_{c\in N_X(i)}u_c \right). \]

Thus the graphical tensor network and the explicit stabilizer sum are two representations of the same object. The tensor network is useful because it reorganizes the exponentially large sum into a structured sequence of local contractions.

Because the 36 written \(X\)-stabilizer generators have six linear dependencies,

\[ \boxed{ Z_\lambda(s) = 2^{-6}\widetilde Z_\lambda(s) = 2^{-6} \operatorname{tTr} \left[ \prod_{c=1}^{36} C_c \prod_{i=1}^{72} W_i^{(b_i^{(\lambda)})} \right]. } \]

This is the total probability mass of all physical errors that both produce syndrome \(s\) and belong to logical sector \(\lambda\). It is the logical-coset partition function.

15. What is the probability of the syndrome itself?

The logical sectors partition all errors compatible with the syndrome. Therefore

\[ \boxed{ P(s) = \sum_{\lambda\in\mathbb F_2^{12}} Z_\lambda(s). } \]

So the phrase “probability of the syndrome” is meaningful, but it is not usually the primary object needed for decoding.

The decoder instead needs the conditional logical posterior

\[ \boxed{ P(\lambda|s) = \frac{Z_\lambda(s)} {\sum_{\mu}Z_\mu(s)}. } \]

Since the denominator is common to all logical sectors, maximum-likelihood decoding only requires

\[ \boxed{ \lambda^\star = \arg\max_{\lambda} Z_\lambda(s). } \]

16. Why does the decoder care about the logical sector?

The measured syndrome does not uniquely identify the physical error. Different physical errors can have the same syndrome, and many of them differ only by stabilizers.

Suppose the true error can be written as

\[ e_{\rm true} = e_0+\lambda_{\rm true}L_X+g, \qquad g\in\mathcal S_X. \]

If the decoder chooses the same logical sector,

\[ \lambda^\star=\lambda_{\rm true}, \]

it may apply the correction representative

\[ c = e_0+\lambda^\star L_X. \]

The residual operator is then

\[ e_{\rm true}+c = g. \]

Since \(g\) is a stabilizer, it acts trivially on the logical code space. The correction is therefore successful even if the decoder did not identify the exact physical error pattern.

A deliberately counterintuitive example

Suppose the true physical error is

\[ e_{\rm true}=X_1X_2, \]

but the decoder applies

\[ c=X_3X_4X_5X_6. \]

At the level of physical qubit locations this looks completely wrong: the decoder did not identify even one of the two qubits that actually suffered an error.

However, suppose

\[ S=X_1X_2X_3X_4X_5X_6 \]

is an \(X\)-stabilizer. Then

\[ e_{\rm true}c = X_1X_2X_3X_4X_5X_6 = S. \]

Since \(S\) acts as identity on the code space,

\[ S|\psi_L\rangle=|\psi_L\rangle, \]

the logical information is restored perfectly.

\[ \boxed{\text{The decoding is 100% successful even though no physical error location was guessed correctly.}} \]

This is why stabilizer decoding is fundamentally a problem of identifying the correct equivalence class, not reconstructing the exact microscopic error pattern.

By contrast, if the decoder chooses the wrong logical sector, then

\[ e_{\rm true}+c = (\lambda_{\rm true}+\lambda^\star)L_X+g, \]

which contains a nontrivial logical \(X\) operator. The syndrome can be removed while the encoded information is still wrong. That is a logical decoding failure.

17. The complete decoding pipeline

\[ e_{\rm true} \longrightarrow s=H_Ze_{\rm true}^T \] \[ s \longrightarrow e_0 \quad \text{such that} \quad H_Ze_0^T=s \] \[ e_0 \longrightarrow b^{(\lambda)} = e_0+\lambda L_X \] \[ b^{(\lambda)} \longrightarrow \text{BB72 tensor network} \] \[ \text{Tensor contraction} \longrightarrow Z_\lambda(s) \] \[ \lambda^\star = \arg\max_\lambda Z_\lambda(s) \] \[ c = e_0+\lambda^\star L_X \] \[ e_{\rm true}+c \in \mathcal S_X \quad \text{if decoding succeeds.} \]

19. The key physical interpretation

The syndrome tells us which affine space of errors is compatible with the measurement, but it does not determine the logical sector inside that affine space.

The logical basis \(L_X\) partitions the same-syndrome error space into \(2^{12}\) logical boxes.

Within each box, the stabilizer generators \(H_X\) generate all physically different but logically equivalent errors.

The tensor network computes

\[ \boxed{ Z_\lambda(s) = \sum_{\text{all physical errors in logical box }\lambda} P(e). } \]

The decoder then chooses the box with the largest total probability mass.

That is the central idea of a tensor-network logical-coset decoder for BB72.
