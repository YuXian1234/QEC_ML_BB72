Three-Qubit Repetition-Code Quantum Error Correction on Quantinuum Nexus

Technical report: ideal validation, H2 native-noise benchmarking, controlled bit-flip scaling, multi-round active correction, and a real H2-1 feedback demonstration.
Bottom line. The four finalized experiments establish a coherent QEC workflow for the three-qubit repetition code. The ideal emulator verifies the syndrome and feedback logic exactly; the H2 noise model shows that the same loop remains functional but that active QEC has nonzero circuit overhead; the controlled-\(X\) benchmark reproduces the expected \(P_L=3p^2-2p^3\) scaling and demonstrates the advantage of repeated correction as errors accumulate; and the real H2-1 run executes the complete mid-circuit-measurement + classical-feed-forward loop successfully in 20/20 shots. The present decoder is a simple in-circuit lookup rule and the code protects only against \(X\)-type bit flips, so this report should be read as a validated QEC control-flow and benchmarking baseline rather than a fault-tolerance threshold study.

1. Three-qubit repetition-code QEC scheme

1.1 Code space and error model

The experiments use the logical zero state

\[ |0_L\rangle=|000\rangle. \]

The code is designed to diagnose and correct a single \(X\)-type bit flip. It is therefore a useful minimal QEC control-flow example, but it is not a full distance-3 quantum memory against arbitrary single-qubit Pauli errors.

1.2 Syndrome extraction

Two parity checks identify which data qubit flipped:

\[ s_0=d_0\oplus d_1,\qquad s_1=d_1\oplus d_2. \]
ErrorSyndrome \((s_0,s_1)\)Register value \(s_0+2s_1\)Correction
none(0,0)0none
\(X_0\)(1,0)1\(X_0\)
\(X_1\)(1,1)3\(X_1\)
\(X_2\)(0,1)2\(X_2\)

One ancilla qubit is reused to measure the two parities. After each mid-circuit measurement the ancilla is reset, allowing the next check to use the same physical ancilla resource.

1.2.1 Gate-level extraction of the syndrome

The syndrome bits are not obtained by measuring the data qubits directly. Instead, the parity of two data qubits is coherently copied onto an ancilla initialized in \(|0\rangle_a\), and only the ancilla is measured. For the first check,

\[ s_0=d_0\oplus d_1, \]

the circuit fragment is

CX(data[0], ancilla[0])
CX(data[1], ancilla[0])
Measure(ancilla[0], syndrome[0])
Reset(ancilla[0])

Starting with \(a=0\), the first CNOT maps the ancilla value to

\[ a=0\oplus d_0=d_0, \]

and the second CNOT gives

\[ a=d_0\oplus d_1. \]

Therefore measuring the ancilla returns exactly the parity bit

\[ \boxed{s_0=d_0\oplus d_1}. \]

The ancilla is then reset to \(|0\rangle_a\) and reused for the second check: 

CX(data[1], ancilla[0])
CX(data[2], ancilla[0])
Measure(ancilla[0], syndrome[1])
Reset(ancilla[0])

which similarly yields

\[ \boxed{s_1=d_1\oplus d_2}. \]
Data pattern\(s_0=d_0\oplus d_1\)\(s_1=d_1\oplus d_2\)Syndrome
\(000\)00\((0,0)\)
\(100\) — \(X_0\)10\((1,0)\)
\(010\) — \(X_1\)11\((1,1)\)
\(001\) — \(X_2\)01\((0,1)\)
Example: middle-qubit error. Starting from \(|000\rangle\), an injected \(X_1\) error produces \(|010\rangle\). The first ancilla measurement gives \(0\oplus1=1\), and the second gives \(1\oplus0=1\), so the measured syndrome is \((1,1)\). The classical decoder therefore identifies the middle qubit and applies \(X_1\), returning the state to \(|000\rangle\).

In stabilizer language these parity measurements correspond to the checks \(Z_0Z_1\) and \(Z_1Z_2\). A parity bit 0 corresponds to stabilizer eigenvalue \(+1\), while parity bit 1 corresponds to eigenvalue \(-1\). The key point is that the circuit extracts error information from the ancilla without directly measuring the encoded logical data.

1.3 Decoder implementation

The decoder is deliberately simple. It is encoded directly as classical conditions inside the circuit:

X(data[0], condition=reg_eq(syndrome, 1))
X(data[1], condition=reg_eq(syndrome, 3))
X(data[2], condition=reg_eq(syndrome, 2))

This is a lookup decoder, not a user-defined Wasm decoder. The purpose of the current experiments is to validate QEC feedback and benchmarking methodology before moving to more complex decoders.

2. Functional validation: ideal, noisy, and no-QEC baseline

2.1 Ideal emulator: verify the control logic first

The walkthrough deliberately injects an error on the middle data qubit:

\[ |000\rangle\xrightarrow{X_1}|010\rangle. \]

The expected syndrome is \((1,1)\), which corresponds to register value 3 and therefore triggers \(X_1\). With the H2 emulator noise model disabled, 100 shots produced:

Result. The ideal run establishes that the parity measurements, syndrome bit ordering, integer encoding, conditional branches, and final correction are mutually consistent.

2.2 H2-Emulator native noise: same circuit, non-ideal operations

The same circuit was then run with noisy_simulation=True for 1000 shots. The deliberately injected \(X_1\) error remained the target error, but the syndrome-extraction and correction operations were now subject to the H2 emulator noise model.

The final-state failures were distributed among a small number of other physical bit strings, showing that the feedback loop remains highly reliable but is no longer perfect once the operations themselves are noisy.

2.3 No-QEC baseline and its interpretation

The retained baseline applies the same deterministic \(X_1\) error but removes syndrome extraction, decoding, and correction. Out of 1000 shots, 998 ended in \(010\), one ended in \(000\), and one in \(011\). The baseline exact-\(000\) success rate was therefore 0.001, compared with 0.993 for the active-QEC circuit.

Important caveat. This is a functionality baseline, not a natural logical-error benchmark. The baseline is almost guaranteed to fail because the \(X_1\) error is deliberately inserted. The comparison demonstrates that the QEC loop can detect and repair a known bit flip; it should not be interpreted as a claim that QEC reduced an intrinsic 99.9% hardware error rate to 0.7%.

3. H2 native-noise benchmark: redundancy versus active-QEC overhead

The native-noise benchmark removes the deliberately injected error. All three circuits start in logical zero and are exposed only to the H2-Emulator noise model. Each strategy is run for 10,000 shots:

StrategyObserved error rateRaw observation
Bare physical qubit0.00055 errors in 10,000 shots
Encoded + final majority0.0000 observed18 single-bit physical errors, but no majority-vote logical failures
Encoded + active QEC0.001414 logical failures in 10,000 shots

The encoded-majority strategy benefits from redundancy without paying the full active-QEC circuit cost. By contrast, the active-QEC circuit introduces four data–ancilla CNOTs, two mid-circuit measurements, resets, and conditional corrections. In this short and already-low-error regime, that extra control overhead is large enough that active QEC does not outperform the simpler encoded strategy.

Interpretation. Active QEC is not free. A correction cycle is useful only when the errors it removes outweigh the errors introduced by syndrome extraction and feedback. This motivates a repeated-noise benchmark in which error accumulation has time to become important.

4. Controlled bit-flip benchmark

4.1 Controlled \(X\)-error channel

To isolate repetition-code behavior from the details of the H2 native noise model, the controlled benchmark disables native emulator noise and deliberately applies independent \(X\) flips with probability \(p\) to the data qubits.

A reusable “coin” qubit is rotated and measured so that the probability of outcome 1 is \(p\):

\[ R_y(\theta)|0\rangle = \cos\frac{\theta}{2}|0\rangle + \sin\frac{\theta}{2}|1\rangle, \qquad \sin^2\frac{\theta}{2}=p. \]

Thus

\[ \theta=2\arcsin\sqrt{p}. \]

If the coin measurement is 1, a conditional \(X\) is applied to the selected data qubit. The coin is then reset and reused. This produces the channel

\[ \rho\mapsto(1-p)\rho+pX\rho X \]

without adding the H2 native noise model on top.

4.2 Single-round theory

For a bare physical qubit,

\[ P_{\mathrm{phys}}=p. \]

For the three-qubit repetition code, a logical failure requires two or three data-qubit flips:

\[ P_L = 3p^2(1-p)+p^3 = 3p^2-2p^3. \]

The leading-order scaling changes from \(O(p)\) to \(O(p^2)\), which is the central theoretical signature that the repetition code suppresses single bit flips.

5. Multi-round error accumulation and the value of repeated correction

5.1 Why the no-active-QEC error is not \(Rp\)

When one physical bit is exposed to \(R\) independent \(X\)-flip opportunities, only the parity of the number of flips matters because \(X^2=I\). The probability of ending with an odd number of flips is

\[ r_R = \sum_{k\ {\rm odd}} \binom{R}{k}p^k(1-p)^{R-k} = \frac{1-(1-2p)^R}{2}. \]

If no active correction is applied between rounds, the final three-qubit majority-vote failure is

\[ P_L^{\mathrm{no\,active}} = 3r_R^2-2r_R^3. \]

5.2 Active correction after every round

For one idealized QEC round, the logical flip probability is

\[ q=3p^2-2p^3. \]

If the code is corrected after each error round, the multi-round logical parity evolves with

\[ P_L^{\mathrm{active}} = \frac{1-(1-2q)^R}{2}. \]

The two schedules being compared are therefore:

\[ \text{No active QEC:}\quad E\rightarrow E\rightarrow E\rightarrow\cdots\rightarrow \text{final majority}, \] \[ \text{Active QEC:}\quad E\rightarrow QEC\rightarrow E\rightarrow QEC\rightarrow\cdots. \]

At one round, final majority decoding already corrects a single physical error, so active correction adds little. As the number of rounds grows, the no-active strategy allows errors to accumulate before the final decode. At \(R=10\), the observed logical error is 24.41% without intermediate correction but only 6.68% with QEC after every round.

Core physical lesson. The value of active QEC is temporal: it repeatedly removes correctable errors before later errors can combine with them to cross the code's correction capability. The multi-round experiment makes this advantage visible much more clearly than a single-round comparison.

The experiments establish a validated QEC workflow and a clean separation between correctness, overhead, controlled-noise scaling, repeated correction, and real-hardware execution.

The most important conceptual result is that QEC performance cannot be judged from a single recovery example alone. The native-noise benchmark exposes the cost of the correction circuitry, while the controlled multi-round benchmark exposes the benefit of removing errors before they accumulate. These two observations together give the correct qualitative picture: active QEC is a tradeoff between error removal and QEC overhead, and its advantage emerges when the protected evolution is long enough for uncorrected errors to compound.

9. Conclusion

The four finalized notebooks form a compact but logically complete QEC study. The ideal walkthrough verifies the basic syndrome and feedback mechanism. The native H2 noise benchmark shows that active QEC carries real operational overhead and is not automatically advantageous in short circuits. The controlled bit-flip experiments quantitatively recover the expected repetition-code scaling and, more importantly, demonstrate how repeated active correction suppresses accumulated errors over many rounds. Finally, the H2-1 experiment confirms that the same mid-circuit measurement and classical feedback architecture can execute on real trapped-ion hardware.

Taken together, the results provide a clean baseline for the next research step: replacing the simple lookup decoder with a genuinely algorithmic decoder and extending from a pedagogical bit-flip code to small CSS/qLDPC/BB codes where real-time decoding complexity becomes the central problem.
